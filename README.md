# Minesweeper

Minesweeper built with HTML5, CSS3 and vanilla ES5 JavaScript for the
Desarrollo y Arquitecturas Web course (UAI).

## Project structure

- `index.html` - game page
- `css/` - stylesheets
- `js/` - game scripts
- `img/` - images
- `audio/` - sound effects
